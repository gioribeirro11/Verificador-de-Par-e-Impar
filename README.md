# Verificador de Par ou Ímpar

Programa em Python que recebe um número inteiro e informa se ele é par ou ímpar.

## Como funciona

1. O usuário digita um número inteiro.
2. O programa usa o operador de resto (`%`) para dividir o número por 2.
3. Se o resto for `0`, o número é par; caso contrário, é ímpar.

## Requisitos

- Python 3.6 ou superior

## Como executar

```bash
python Verificador_de_Par_ou_Ímpar.py
```

## Exemplo de uso

```
Digite um numero: 7
O numero é ímpar
```

```
Digite um numero: 10
O numero é par
```

## Conceitos praticados

- Entrada de dados com `input()`
- Conversão para inteiro com `int()`
- Operador de módulo (`%`)
- Estrutura condicional `if` / `else`
